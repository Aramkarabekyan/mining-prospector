РАЗВЁРТЫВАНИЕ MINING PROSPECTOR В RENDER

Важное уточнение: Render не получает доступ к вашему аккаунту от Copilot автоматически. Я подготовил Blueprint, который создаёт два сервиса: веб-приложение и закрытый поисковый SearXNG.

ШАГ 1. Загрузить проект в GitHub
1. Откройте https://github.com/new и создайте приватный репозиторий mining-prospector.
2. Распакуйте архив mining_prospector_no_api_key.zip на компьютере.
3. Загрузите ВСЕ файлы и папки из mining_prospector_api в корень репозитория GitHub (не загружайте сам zip вместо файлов). В корне должны лежать render.yaml, Dockerfile, server.js, package.json, index.html и папка searxng.
4. Сделайте Commit changes в GitHub.

ШАГ 2. Подключить GitHub к Render
1. В Render Dashboard нажмите New + -> Blueprint.
2. Подключите GitHub, если Render ещё не подключён.
3. Выберите репозиторий mining-prospector и ветку main.
4. Render прочитает render.yaml и покажет два сервиса.
5. Проверьте регион Frankfurt. Нажмите Apply.

ШАГ 3. Дождаться развертывания
Render соберёт Node.js приложение и отдельный SearXNG. Веб-приложение получит публичный адрес вида https://mining-prospector.onrender.com. Используйте фактический адрес из Dashboard.

ВАЖНО ПРО СТОИМОСТЬ
Blueprint задаёт оба сервиса как Starter, поскольку поисковый движок должен постоянно работать как закрытый private service. Это платные ресурсы Render. До нажатия Apply проверьте показанную Render месячную стоимость. Не подтверждайте ресурсы, если стоимость не подходит.

ОГРАНИЧЕНИЯ ТЕКУЩЕЙ ВЕРСИИ
- Это развертывание делает доступным поиск в браузере, но лиды пока сохраняются в localStorage конкретного браузера. Для общей базы между устройствами понадобится следующий этап: подключить Render PostgreSQL и авторизацию.
- SearXNG выдаёт публичные веб-страницы и сниппеты, не гарантирует email/телефоны и может сталкиваться с ограничениями поисковых движков.
- Не публикуйте SearXNG как отдельный публичный сервис. В Blueprint он задан как private service.
- Для первого запуска нужен GitHub репозиторий, доступный Render.

Если Render покажет ошибку Blueprint, пришлите текст ошибки или скриншот. Не публикуйте секреты/токены.
