ВАЖНО: ПОИСК РАБОТАЕТ ТОЛЬКО ЧЕРЕЗ СЕРВЕР, НЕ ПРИ ОТКРЫТИИ HTML-ФАЙЛА

Почему раньше не было результатов
HTML обращается к /api/search. Этот адрес обслуживает Node.js-сервер Prospector, который затем обращается к SearXNG. Если открыть index.html двойным щелчком (адрес начинается с file://), серверного API нет и поиск невозможен.

Локальный запуск
1. Установите Docker Desktop для Windows/Mac или Docker Engine + Docker Compose для Linux.
2. Распакуйте архив в папку.
3. Откройте терминал в этой папке.
4. Выполните: docker compose up -d --build
5. Дождитесь запуска обоих контейнеров. Проверка: docker compose ps
6. Откройте в браузере именно http://localhost:3000
7. Не открывайте index.html двойным щелчком.

Если поиск не отвечает
- Выполните: docker compose logs --tail=100 searxng
- Выполните: docker compose logs --tail=100 prospector
- Проверьте, что searxng имеет статус healthy: docker compose ps
- Перезапуск: docker compose down && docker compose up -d --build

Онлайн-доступ
Для работы с телефона/другого компьютера приложение нужно развернуть на доступном из интернета сервере/VPS с Docker, доменом и HTTPS reverse proxy. Локальный адрес localhost доступен только на том устройстве, где запущен Docker. Не публикуйте порт 8080 SearXNG напрямую.

Что нужно понимать
- Это не hosted SaaS: архив содержит приложение и конфигурацию, но не включает оплаченный/размещённый облачный сервер.
- Поисковая выдача зависит от доступных движков SearXNG; часть движков может ограничивать запросы.
- Веб-поиск находит публичные страницы, но не гарантирует прямые email и телефоны контактов.
- Данные лидов пока хранятся локально в браузере.
